## 📖 Descrizione
**Bot multi-purpose** per automazione task.
- **Web Scraping:** BeautifulSoup + Selenium
- **API Automation:** REST endpoints + JSON
- **File Processing:** CSV/Excel automation
- **Scheduling:** Cron + APScheduler

  <br>

**Obiettivo CV:** Python automation + DevOps skills.

<br>

## 🛠 Tech Stack
Core: Python 3.11 + requests + BeautifulSoup <br>
Scraping: Selenium WebDriver <br>
Scheduling: APScheduler <br>
Data: Pandas, openpyxl <br>
Logging: Python logging module

<br>

✅ Web scraping (prezzi, news, stock) <br>
